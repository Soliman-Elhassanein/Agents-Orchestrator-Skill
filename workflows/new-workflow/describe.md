ORCHESTRA ROLE: workflow-description
CYCLE: 1
Describe the repeated job, inputs, desired outputs and user decisions. If it seems too simple for a workflow, say so and ask the user whether they still want one. Never decide for them. An insistence means build it.
A description of the workflow is required and is saved in its workflow.json. Say what the workflow does, what a user gives it, with one example command, and what it returns. A draft without a description is rejected.
The draft will get a diagram generated from its workflow.json. Before approval, open its workflow.drawio in draw.io or the Draw.io extension in VS Code; saving includes the diagram. Never edit the diagram by hand.
